# 音庭（おとにわ）

音の種をお庭へ置くだけで、小さな曲が育つブラウザ版プロトタイプです。

8つの音の種があります：✨きらきら、🌱ふわふわ、💧ぽこぽこ、🖤ざらざら、🌧️しとしと、🍃そよそよ、🌳こつこつ、🐦ぴるぴる。

## スマートフォンで試す（いちばん簡単）

### PCですること

1. PCとスマートフォンを、同じWi-Fiにつなぎます。
2. 音庭フォルダーにある **`スマホで音庭を開く.bat`** をダブルクリックします。
3. 黒い画面に黄色で表示されたアドレスを確認します。

表示例：

`http://192.168.1.23:8000`

### スマートフォンですること

1. ChromeやSafariを開きます。
2. PCの黒い画面に表示されたアドレスを、そのまま入力します。
3. 音庭が開いたら成功です 🌱🎶

遊んでいる間は、PCの黒い画面を閉じないでください。終了するときは、その画面を閉じて大丈夫です。

## 最初だけ確認画面が出た場合

Windowsから通信の許可を聞かれたら、次のようにします。

1. **「プライベート ネットワーク」** にチェックを入れます。
2. **「アクセスを許可する」** を押します。

「パブリック ネットワーク」はチェックしなくて大丈夫です。

## つながらないとき

このPCのWi-Fiが「パブリック」になっていると、スマートフォンからの通信が止められます。次の操作を最初に1回だけ行います。

1. 音庭フォルダーの **`音庭の通信を許可する（最初に1回）.bat`** をダブルクリックします。
2. 「このアプリがデバイスに変更を加えることを許可しますか？」と表示されたら、**「はい」**を押します。
3. `OTONIWA network access is ready.` と表示されたら、その画面を閉じます。
4. **`スマホで音庭を開く.bat`** をもう一度ダブルクリックします。
5. 黒い画面の黄色いアドレスをスマートフォンで開きます。

この設定が許可するのは、プライベートWi-Fiで音庭が使うTCP 8000番だけです。

まだつながらない場合は、上から順番に確認します。

1. PCとスマートフォンが、本当に同じWi-Fiか確認します。
2. スマートフォンへ入力したアドレスが、黒い画面の表示と同じか確認します。
3. PCやスマートフォンのVPNを一時的に切ります。
4. PCの黒い画面を閉じ、`スマホで音庭を開く.bat` をもう一度ダブルクリックします。

スマートフォンでは `localhost` や `127.0.0.1` を使いません。

## PCだけで遊ぶ場合

`index.html` をダブルクリックします。

- 種をお庭へドラッグすると、自動で演奏が始まります。
- 上へ置くほど高い音になります。
- 右へ置くほど、ループの後ろで鳴ります。
- 置いた種を押すと大きくなり、音量も大きくなります。
- 置いた種は、あとからドラッグして動かせます。
- 種を少し長押しすると、その種だけ摘み取って消せます。
- 「成長速度」のスライダーで、50〜160 BPMの間に調整できます。演奏中にも変えられます。

音が出ない場合は、画面上の「再生」を一度押してください。

## 生まれた曲を録音する

1. 音の種をいくつか置きます。
2. 画面上の **「録音」** を押します。演奏と録音が始まります。
3. 好きなところまで聴いたら、赤くなった **「録音中」** をもう一度押します。
4. お庭の下に出る再生ボタンで聴き直せます。
5. 残したいときは **「端末に保存」** を押します。

録音するのは音庭の音だけです。スマートフォンやPCのマイクは使わないため、マイクの許可は必要ありません。

## 使っているもの

- HTML / CSS / JavaScript
- Web Audio API
- 外部ライブラリ・外部音源なし
- スマートフォン用の起動ファイルもPython不要
